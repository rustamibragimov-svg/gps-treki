Пока разбор JSON плана не написан, шапку вбиваем руками: этого хватает, чтобы считать план / факт / Δ по километражу. Остановки появятся, когда разберём ответ маршрутизатора.

Как выгрузить данные из маршрутизатора
  1. Откройте карточку маршрута, F12 → вкладка «Сеть», фильтр Fetch/XHR.
  2. Нажмите «Пересчитать GPS-метрики».
  3. Найдите запрос history?courierId=….
  4. Правой кнопкой → Копировать → Копировать ответ.
  5. Вставьте сюда, впишите водителя и регион, нажмите «Добавить трек».
  6. Плановый километраж возьмите из карточки маршрута и внесите в «Добавить план».
